# CyberShakti_Project
Network Forensics & Incident Reconstruction

This chapter presents an overview of the digital forensic investigation conducted on the Vulnerable Vault environment, focusing on the analysis of a simulated cyberattack involving compromised TLS 1.2 encrypted communications. It outlines the purpose of the investigation, summarizes the incident, and defines the project's objectives and forensic scope. The chapter establishes the foundation for understanding how forensic techniques were applied to reconstruct the attack sequence, analyze network evidence, and identify the security weaknesses that enabled the breach.
